RHF BILLET REGISTER - ANDROID INSTALL GUIDE

OPTION A - Install from Chrome (no APK, easiest)
1. Upload this whole folder to any free HTTPS host:
   Netlify Drop (app.netlify.com/drop), GitHub Pages, or Cloudflare Pages.
2. Open the link in Chrome on Android -> menu (3 dots) -> "Install app" / "Add to Home screen".
3. It opens full-screen like a normal app and works offline after first load.

OPTION B - Real APK file (to share/download)
1. Host the folder as in Option A.
2. Go to pwabuilder.com, paste your link, choose Android -> Download package.
3. Unzip, install the APK on the phone (allow "install unknown apps"), or upload to Play Store.

NOTES
- Data is saved on the device (browser storage). Use History & Export -> Excel / Backup regularly.
- Each phone keeps its own data; there is no cloud sync in this version.
